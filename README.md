# End-to-End Software Testing & Automation Project

## Application
**SauceDemo** — a demo e-commerce web application used for manual testing and UI automation.

## Project Scope
1. Manual testing documentation
2. Selenium + TestNG + Maven web automation using POM
3. API testing with Postman
4. API automation with Rest Assured
5. AI-assisted testing evidence
6. Jenkins CI/CD configuration
7. Git/GitHub project organization
8. Final report and presentation outline

## Repository Structure
- `01_Manual_Testing` — requirements, test plan, scenarios, cases, execution and defects
- `02_Web_Automation` — Maven Selenium/TestNG POM framework
- `03_API_Testing` — Postman collection and Rest Assured project
- `04_AI_Testing` — AI-assisted test design evidence
- `05_DevOps_Jenkins` — Jenkinsfile and CI/CD evidence
- `06_Final_Report` — final project report
- `07_Presentation` — presentation outline

## Run Web Automation
```bash
cd 02_Web_Automation
mvn clean test
```

## Run API Automation
```bash
cd 03_API_Testing/RestAssured
mvn clean test
```

## Jenkins
The project is designed for a Jenkins Maven build using `pom.xml` and `Jenkinsfile`.
