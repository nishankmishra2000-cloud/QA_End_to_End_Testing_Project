# Final Project Report

## 1. Application Overview
SauceDemo is used as the demo e-commerce web application.

## 2. Manual Testing Summary
Requirements, test plan, scenarios, test cases, execution and defect-report templates are provided.

## 3. Automation Framework Design
Maven + Selenium + TestNG + Page Object Model. Locators/actions are kept in page classes and tests contain assertions.

## 4. API Testing Results
Postman collection covers GET, POST, PUT, PATCH and DELETE. Rest Assured tests validate response codes, content type and JSON fields.

## 5. CI/CD Flow
GitHub → Jenkins → Maven → UI/API tests → test reports/artifacts.

## 6. AI Tool Usage
AI is used for test-case generation, negative scenarios, coverage improvement and regression ideas.
